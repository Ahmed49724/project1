Expert Priority Decision

I saw the Teacher Command Center interest, but the safest product order starts with the account and permission foundation first.

Recommended Build Order
1

Parent + Secure Auth Foundation

Parent account owner, child sub-accounts, student PIN/code access, consent, RBAC, and safe session handling.

2

Student Learning Shell

Daily quest map, immersive lesson screen, bilingual RTL/LTR mode, progress, rewards, and existing Arabic/Verb Lab integration.

3

Teacher Command Center

Lesson upload, assignment builder, grading queue, and live-session scheduling after the account model is stable.

4

Parent Oversight + Reports

Weekly digests, portfolio export, approvals, subscriptions, and direct messaging.

Why this order wins

  • Protects child data before scaling usage.
  • Prevents reworking student and teacher flows later.
  • Makes Google/email/student-code login decisions concrete.
  • Turns the current site into one coherent platform shell.

Tradeoff

  • The exciting teacher tools come later.
  • Early work is less flashy, but it reduces the most risk.
  • Requires choosing the account model before adding more games.
